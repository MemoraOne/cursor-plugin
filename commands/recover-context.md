# Recover MemoraOne Context

Use MemoraOne to recover the persistent context for the current project before continuing.

Call `memora_ask_with_memory` and retrieve the most relevant information about:

- prior architectural decisions
- previous implementation choices
- recent fixes and migrations
- unresolved work
- important project facts
- the most likely next step based on prior work

Then summarize the recovered context clearly and use it to continue the current task.

Do not invent missing history. If MemoraOne does not contain enough context, state what is missing.
